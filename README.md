# Watch Atelier — parallel M1 asset candidate

This branch preserves the committed original asset candidate as a **source overlay
on the shared public main base**, so it can be reviewed and merged when ready.
It is not a verified integrated renderer release or a physically qualified watch.
The host code is retained, but older renderer interfaces and tests still require
reconciliation. Integration and visual acceptance remain pending. Use `main` for
the verified studio. Main's passing test counts do not apply to this changed branch.

Included: one original concept watch, semantic dial projection, separate hand pivots,
two hand styles, two strap finishes, three editable starters, procedural appearance
recipes, studio/cameras, lifecycle tests and inspection fixtures.

Runtime and tests are unchanged from the committed asset candidate. Private handoff
prompts, personal context, historical commits, machine-specific reports and all
uncommitted work are excluded from this public snapshot. Licenses and the reviewed
source/dependency registry are retained under `docs/assets/`.

See [integration boundary](docs/assets/INTEGRATION.md). Never merge this older
renderer over the current host without explicit adaptation and combined tests.
