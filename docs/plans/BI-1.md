# BI-1 public scope

Revision-bound public-source research beside the local studio: confirm requirements,
consent, discover parts, inspect evidence and unknowns, select a provisional plan,
calculate partial costs, view assembly resources, save/reopen/export.

`evals/bi1-cases.json` and `evals/bi1-test-map.json` retain the exact evaluation
inventory and test mapping. Positive controls accompany missing evidence, fabricated
citations, variant mismatch, hard incompatibility, quantity tiers/MOQ, bundle
double-counting, mixed currencies, stale results, imported trust, private-data
leakage and provider failure cases. Mapping alone is not proof of passing coverage.

The implementation is a bounded, incomplete candidate. See ../VERIFICATION.md for
executed checks and missing gates. No private-image analysis, automatic watch
substitutions, purchases, supplier outreach, detailed manufacturing or BI-2/3.
