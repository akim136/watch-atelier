# Public repository working agreement

Inspect existing code and instructions before changes. Plan and challenge material
changes, implement small slices, add regression tests, and report actual results.
No new production dependencies without explicit approval.

One versioned canonical design and validated mutation boundary own editable state.
Preserve locks, history, independent variants, persistence and export consistency.
Research is a read-only revision-bound sidecar. Missing evidence is unknown, not
pass. Renderer appearance is never proof of physical fit or manufacturing readiness.

This repository contains curated public snapshots. Never merge or push private
development history into it. Review both content and ancestry before publication.
Keep credentials, private images, exports, raw prompts, personal context and local
reports out of Git. Do not force-add ignored material. Use noreply commit identity.

Parallel asset branches are unintegrated source overlays. Preserve their ownership
and the current host schema; do not silently introduce a second design model.
Test renderer changes through live, comparison and export paths before acceptance.

Run the commands documented in README. Browser-test nontrivial UI changes. Never
weaken tests or silently replace baselines. Human acceptance is separate from tests.
Do not deploy, spend, contact suppliers, purchase or release manufacturing files
without explicit authorization.
